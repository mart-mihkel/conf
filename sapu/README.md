# SAPU

Configs and scripts for SAPU machines. The private research environment for sensitive data called SAPU, is a secure computing environment designed and offered by the University of Tartu HPC Center (UT HPC). In SAPU environment analysts can work on sensitive data, reducing the possibility of unauthorized copying, transfer or extraction of data and offering a higher security level than a standard high-performance computing cluster. The SAPU environment is a special and separate virtual machine that meets high-security requirements and is located in the UT HPC data center in Estonia.
